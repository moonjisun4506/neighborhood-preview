# 소음 자료 점검 (2026-11-27)

이 문서는 신규 공공데이터 API 연결 전의 조사 기록입니다. 현재 철도 API·환경영향평가 API의 실제 인증과 CSV 다운로드·연결 결과는 [noise-public-data.md](noise-public-data.md)를 참고하세요.

## 연결한 공식 자료

- 국가소음정보시스템: https://www.noiseinfo.or.kr/noise/data.do
- 공개 페이지의 위치 JSON: https://www.noiseinfo.or.kr/api/noise/getSpot.dojson
- 공개 페이지의 측정 JSON: https://www.noiseinfo.or.kr/api/noise/getData.dojson
- 별도 키 없이 실제 응답을 확인했다. 공개 웹사이트에서 사용하는 JSON이며, 버전이 보장된 외부용 API 계약은 아니다. 형식 변경·부분 반환·조회 실패를 자료 없음으로 처리하지 않는다.
- EA(환경 자동): 제공 건수 551 / 실제 위치 행 550. 공식 페이지의 날짜 선택 상한은 2026-06-30. 앱은 2026년 6월의 지점별 마지막 유효 일평균을 표시한다. 주간 평균·실시간 값이 아니다.
- EM(환경 수동): 실제 위치 1,461곳. 2026년 1~4분기를 요청하고 반환된 유효 분기 중 최신 자료를 사용한다. 조계사 후문 앞은 2분기 자료가 최신으로 반환되었다. daytimeAve / nightAve는 주·야간 평균, hour9Dt / hour23Dt는 해당 09시·23시 기록의 날짜다. 분기 전체를 상시 측정한 값으로 해석하지 않는다.
- R(철도): 실제 위치 41곳. 2026년 상반기 자료를 제공한다. 야간값은 22시 값이며 야간 전체 평균이 아니다. 개별 측정일은 반환되지 않는다.
- 위치는 WGS84 측정지점 좌표다. 거리 필터는 선택 집 좌표에서 지점까지의 직선거리로 적용한다. 종류별 최대 8곳, 도로변·철도 참고 위치는 합계 최대 3곳이다.
- 도로변 참고는 EA의 regnName=도로, 철도 참고는 공식 R 측정망만 사용한다. 측정지점 좌표를 도로·선로 형상 또는 실제 소음원 위치로 바꾸어 해석하지 않는다. 지상·지하 철도 여부도 추측하지 않는다.

## 파일·별도 API·지도 검토

- 환경 자동 확정 일평균 CSV: https://www.data.go.kr/data/3042013/fileData.do (이용허락범위 제한 없음). 파일의 측정일과 게시일은 다르므로 게시일을 측정시점으로 사용하지 않는다.
- 철도 CSV: https://www.data.go.kr/data/15065383/fileData.do
- 별도 철도 REST 상품: https://www.data.go.kr/data/15164190/openapi.do — serviceKey 및 활용 신청이 필요하다. 이 작업에서는 기존 무키 공개 JSON 경로를 유지했다. 상품 소개의 실시간 표현을 기존 반기 측정값에 적용하지 않는다.
- 서울 도로교통 파일: https://data.seoul.go.kr/dataList/OA-15473/F/1/datasetView.do — 시청·신사·신촌·성수 4개 도로변 측정 지점 자료. 서울 전체나 임의 집 좌표의 소음도가 아니다. 다운로드 파일의 각 측정일·위치 결합을 검증하지 않아 앱의 수치로 추가하지 않았다.
- 소음지도 작성방법: https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000273170 — 측정/예측 지도는 구분해야 한다. 이번 조사에서는 카카오맵 중첩을 허용하는 공개 도로·철도 소음 WMS/타일의 엔드포인트·좌표계·재사용 조건을 함께 확인하지 못했다. 예측 레이어, 보간 지도, 소음 등급은 구현하지 않았다. 별도 기관의 레이어 및 사용 조건 확인이 필요하다.
- 큰 도로·지상 철도의 선형과 집에서의 실제 이격거리를 확정할 공식 공간 데이터 연결은 미구현이다. 역/정류장 거리로 선로 거리를 대체하지 않는다.
- 카카오 공식 로드뷰 링크 안내: https://apis.map.kakao.com/web/guide/#roadviewurl — 선택 좌표의 외부 로드뷰 링크만 제공한다. 사진의 촬영 시점과 현재는 다를 수 있으며 소음은 확인할 수 없다.

## 해석과 AI

측정값은 출처·과거 측정기간·측정지점과 함께 제공하며 집의 소음으로 단정하지 않는다. 소음지도 예측값은 조회하지 않았으므로 AI에 입력하지 않는다. 측정값이 없을 때는 확인된 관측 위치 또는 현장 확인 안내만 근거로 제공한다. 대규모 도로·지상 철도 존재, dB, 조용함/시끄러움, 위험 등급을 추측하지 않는다.
